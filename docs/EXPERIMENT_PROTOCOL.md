# 评估协议

训练、验证和测试使用独立清单。验证集用于选检查点和阈值；最终测试前固定全部设置。同一源图像裁出的 patch 应按原图或采集场景分组后再划分。`audit_dataset.py` 检查文件主干及解码后像素的跨划分重复，不能识别近重复图像、不同裁剪或同一路段带来的泄漏。

旧混合集的 val/test 有镜像关系，论文已说明其用于工程监控。这些结果属于工程监控记录。CPU / CUDA 短程训练另用于检查代码运行，记录见 [测试说明](VALIDATION.md)。

## 通用掩膜评估

- 二值标签与预测按文件主干一一匹配；多余、缺失或重名文件均报错。尺寸必须相同，不自动缩放标签。
- 标签固定以 0.5 二值化。预测可由 `--threshold` 指定阈值；支持布尔值、0/1、0/255 或 [0,1] 概率，不能直接输入 logits。
- CSV 每行是一幅图；`__mean__` 是逐图宏平均，包括计数列也为逐图均值，不是像素池化结果。
- Precision、Recall、Dice、IoU 等沿用原工具的小量稳定项。两幅掩膜均无前景时，前景重叠指标为 0，accuracy 接近 1。比较含空标签数据集时必须统一这一约定。
- 网格按左上角起始，每格 16×16 像素；边缘不足整格时按实际像素数计算占比。前景占比达到 0.05 判阳性。它是图像空间代理指标，没有换算为实际道路面积。
- `tolerance_f1` 以 2 像素方形邻域允许前景位置偏差，两边均为空时为 1。原工具名为 `boundary_f1`，但并未提取轮廓，因此 CSV 使用更准确的名称；它不等同于标准边界 F1。
- clDice 在安装 `scikit-image` 时计算。未安装时写为 NaN，并在 JSON 中记录不可用，不以 0 代替。

与 CSV 同名的 JSON 保存阈值、网格参数、样本数量和输入 SHA-256。源数据清单及哈希报告可能暴露内部样本信息，默认仅留本地。

## 跨模型比较

必须记录检查点、数据清单、模型配置、输入尺寸、预处理与后处理版本，以及阈值选择依据。模型原生脚本可能采用全局计数，不能与通用工具的宏平均混在同一排名中。YOLOv4-DAE 历史补充实验使用过 32×32 网格和 0.005 阈值，只适合该链路前后的配对比较。

小尺寸随机输入检查只验证张量尺寸、有限数值与梯度，不测精度，也不提供可比较的部署 FPS。
